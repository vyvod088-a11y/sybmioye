# Как получить JAR без установки Gradle на Windows

Этот проект уже содержит автоматический сценарий сборки в `.github/workflows/build.yml`.

1. Распакуй `SymbioteEvolution-0.2.0-source.zip`.
2. Создай пустой репозиторий на GitHub.
3. Открой репозиторий → **Add file** → **Upload files**.
4. Перетащи туда содержимое распакованной папки проекта. Не забудь папку `.github`.
5. Нажми **Commit changes**.
6. Перейди во вкладку **Actions** и открой запуск **Build Symbiote Evolution**.
7. Дождись зелёной галочки и скачай архив из раздела **Artifacts**.
8. Распакуй архив артефакта: внутри будет готовый `.jar`.

Если сборка станет красной, открой её, нажми на шаг **Build the mod**, скопируй нижнюю часть ошибки и покажи её разработчику. Не удаляй проект и не меняй версии наугад.
