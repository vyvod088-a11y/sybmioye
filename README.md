# 🖤 Symbiote Evolution 0.2.0

Мод для **Minecraft Java 1.20.1 + Fabric**. Требуется **Java 17** и Fabric API.

## Что в этой версии

- Метеориты могут случайно появляться в Верхнем мире.
- Из метеорита выходит отдельный симбиот с собственной 3D-моделью.
- У модели белые глаза и четыре анимированных щупальца.
- Можно установить связь с симбиотом; характер и доверие сохраняются в мире.
- Четыре формы: боевая, скоростная, защитная и паучья.
- У каждой формы есть пассивные характеристики и отдельная активная способность.
- Диалоги зависят от характера и уровня доверия.
- Можно хвалить симбиота или ругаться с ним: это влияет на доверие и тон реплик.
- Улучшены текстуры метеорита и симбиота; добавлена иконка мода.
- Добавлена команда для тестового появления метеорита.

## Управление

| Клавиша | Действие |
|---|---|
| `G` | Включить / выключить слияние |
| `H` | Переключить форму |
| `Y` | Поговорить с симбиотом |
| `V` | Использовать активную способность |
| ПКМ по метеориту | Выпустить симбиота |
| ПКМ по симбиоту | Установить связь |

Команды в чате:

- `/symbiote status` — показать доверие, характер, форму и состояние слияния.
- `/symbiote talk` — попросить симбиота ответить.
- `/symbiote praise` — похвалить его и повысить доверие.
- `/symbiote scold` — поругать его и снизить доверие.
- `/symbiote meteorite` — создать тестовый метеорит перед игроком.

## Как получить готовый JAR без установки Gradle на свой компьютер

В проект добавлена автоматическая сборка через GitHub Actions. Gradle и Java устанавливаются на сервере сборки автоматически; на своём компьютере вручную устанавливать Gradle не нужно.

1. Открой GitHub и создай новый пустой репозиторий.
2. Распакуй этот ZIP на компьютере. В репозиторий нужно загрузить **содержимое папки проекта**, а не сам ZIP-файл.
3. На странице репозитория нажми **Add file → Upload files** и загрузи файлы проекта вместе с папкой `.github` (в ней лежит файл автоматической сборки `workflows/build.yml`).
4. Нажми **Commit changes**.
5. Открой вкладку **Actions**. Там запустится задача **Build Symbiote Evolution**. Можно также открыть её и нажать **Run workflow**.
6. Когда задача завершится зелёной галочкой, открой её страницу и найди раздел **Artifacts**.
7. Скачай `SymbioteEvolution-0.2.0`, распакуй архив и возьми файл `.jar`.

## Установка в Minecraft

1. Установи Fabric Loader для **Minecraft 1.20.1**.
2. Установи **Fabric API для Minecraft 1.20.1**.
3. Нажми `Win + R`, введи `%appdata%\.minecraft` и нажми Enter.
4. Открой папку `mods`. Если её нет — создай.
5. Положи туда JAR-файл Symbiote Evolution и JAR-файл Fabric API.
6. Запусти профиль Fabric 1.20.1.

## Важно о текущей стадии

Это развиваемый прототип. Сейчас слияние включает эффекты и характеристики, но полноценная замена модели игрока на Веномоподобную форму и длинная кинематографичная анимация превращения ещё не готовы. Общение в этой версии основано на заранее написанных репликах и характере — внешняя нейросеть не подключается. Мод ориентирован на одиночную игру.
